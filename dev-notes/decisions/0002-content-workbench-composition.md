# 内容创作保留 main 外框并组合两个制作引擎

日期：2026-11-12（Australia/Sydney）。状态：本地实现，正式替换待验收。

用户已选择透视穿梭与棱镜脉冲，并要求对齐最新 main 的整体前端。main 已有创作设置、热点生成、
共享素材及人工发布确认；旧混剪工作区包含用户素材和未提交开发，不能整体覆盖新版外框。

采用 `src/services/content-workbench.js` 组合 main 的 Video Studio 外框与独立 montage15 引擎。
只有 `/montage/` 和混剪文件流进入新引擎，热点、创作设置、历史会话及成片库合同继续复用 main。
新建工程仅提供两套用户选定模板，既有工程保存快照。切换路由时持续挂载 iframe，保留草稿及工程状态。

已考虑直接搬入旧工作区外框，但它会覆盖新版导航和设置入口，因此只迁入制作能力。
组合带来嵌套 iframe 的主题与路由协调成本，使用同源消息校验、共享主题脚本和集成回归覆盖。
默认入口不再初始化旧助手桥接，避免无关 CLI 会话阻塞混剪首页；旧接口保持兼容。

导出经内容摘要校验后进入共享素材库，默认 pending，仍需人工确认才能用于发布。
本轮使用独立本地数据，不代表 Docker、Windows 安装器或正式环境已验收。
