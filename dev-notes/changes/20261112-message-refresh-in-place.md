# 评论与私信来新消息时原位更新

2026-11-12。基线 `8b92b6d`（main）。复测发现评论/私信页每来一条新消息仍整页重画，产生闪动。

定时刷新数据变化时，`renderMessages` 改为离屏渲染 + 展示层整理 + `patchBackgroundContent` 合并；卡片和帖子分组加 `data-refresh-key`；帖子分组 `toggle` 只绑定一次。收件箱和私信会话的交互改为点击时查找当前节点与最新数据，避免合并后引用旧节点。后端与轮询频率未改。

追加：原生下拉框改为 macOS 风格弹出菜单（`ui-select.js`，原生 select 保留并照常派发 change），总览周期改为分段控件，折叠区改为旋转箭头，优先系统字体。

验证与测试对比见[完整记录](../../docs/changes/2026-11-12-message-refresh-in-place.md)。未提交、未推送、未部署。

下一步：检查小程序对话、转人工记录、发布任务页的定时刷新；RPA 电脑实测。
