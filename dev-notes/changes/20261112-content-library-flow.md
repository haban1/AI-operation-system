2026-11-12（Australia/Sydney）。基线 `304f707`（main）。

- 统一叫法为“成片库 / 待确认 / 已入库 / 确认入库 / 入库并去发布”。
- 成片库的状态改为带数量的分段切换。
- 混剪导出完成后可直接“加入成片库”（外层工作台按 `montage-<jobId>` 调用原确认接口）。
- 热点页去掉成片库页签，“成片详情”按需显示；保存所选版本后进入成片库的“自动热点 · 待确认”。
- 发布管理改为“从成片库选择”。
