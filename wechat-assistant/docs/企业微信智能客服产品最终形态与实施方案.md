# 企业微信智能客服用户问答呈现效果

## 1. 常见问题直接回答

当用户的问题能够匹配知识库时，系统直接返回已经维护好的标准答案。

```text
用户：课程适合零基础吗？

客服：大部分课程支持零基础学习，老师会从基础概念和实操步骤讲起。
如果你不确定是否适合，可以补充年龄、学习目标和基础情况。
```

呈现效果：

- 回复速度快。
- 相同问题保持统一口径。
- 答案来自人工维护的知识库，不会自由编造。

## 2. 不同问法返回相同答案

用户不需要严格按照标准问题提问。

知识库中的标准问题：

```text
如何联系人工客服？
```

用户可以这样问：

```text
怎么转人工？
人工客服在哪？
我想找老师。
```

系统都会返回：

```text
客服：工作时间内回复“人工客服”，我们会尽快为您转接人工服务。
```

## 3. 问题不明确时主动确认

当用户的表达可能对应多个问题时，系统不会随便选择一个答案，而是先让用户确认。

```text
用户：这个课我不想要了。

客服：请问你想咨询的是哪个课？
```

用户确认后，系统再返回对应的标准答案。

## 4. 用户要求转人工

当用户明确提出转人工时，系统立即识别并返回人工客服提示。

```text
用户：我要转人工客服。

客服：好的，我会为你转接人工客服。
请留下需要咨询的问题和方便联系的方式。
```

类似表达也能识别：

```text
找一下老师
我要人工服务
真人客服
有人能处理吗
```

## 5. 投诉或紧急问题

投诉和紧急问题优先交给人工处理。

```text
用户：我要投诉，这个问题一直没有解决。

客服：已记录你的反馈，我会优先转交人工客服处理。
请补充具体问题和方便联系的方式。
```

## 6. 知识库没有答案

当系统没有找到可靠答案时，不会编造内容。

```text
用户：提出了知识库尚未覆盖的问题。

客服：暂时没有找到匹配的标准答案。
请换个说法再试，或联系人工客服。
```

该问题会被记录，后续由管理员补充到知识库。

## 7. 一次询问多个问题

当用户在一条消息中同时提出多个问题时，LLM 自动识别并拆分问题，再从知识库中分别查找标准答案，最后组合成一条清晰的回复。

```text
用户：课程适合零基础吗？多少钱？周末可以上课吗？

客服：
1. 零基础学习
大部分课程支持零基础学习，老师会从基础概念和实操步骤讲起。

2. 课程费用
课程费用会根据课程类型、课时和班型有所不同，请提供想了解的课程名称。

3. 上课时间
部分课程会安排周末班，具体时间以对应课程和班级安排为准。
```

呈现效果：

- 自动识别一条消息中的多个问题。
- 分别匹配每个问题对应的标准答案。
- 按编号或主题组合回复，方便用户阅读。
- LLM 只负责拆分问题和整理表达，答案内容仍以知识库为准。
- 某个子问题没有答案时，只对该问题提示补充信息或转人工，不影响其他问题的正常回答。

## 8. 用户结束咨询

```text
用户：不用了，结束吧。

客服：本次对话已结束。如需帮助，可以随时重新发起咨询。
```

## 9. 最终呈现效果

用户在企业微信中只需要像正常聊天一样提问，系统会根据情况呈现四类结果：

| 用户问题情况 | 系统呈现效果 |
| --- | --- |
| 问题明确且知识库有答案 | 直接返回标准答案 |
| 用户换了一种表达方式 | 匹配相似问法并返回相同答案 |
| 问题可能对应多个答案 | 先询问用户具体想咨询什么 |
| 一条消息包含多个问题 | 自动拆分并组合多个标准答案 |
| 要求人工、投诉或问题未知 | 提示转人工或联系人工客服 |

最终希望让用户感受到：

> 能回答的问题快速准确回答，不确定的问题先确认，无法处理的问题及时交给人工。
