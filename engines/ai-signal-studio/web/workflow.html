AI SIGNAL / CREATIVE EXPLORATION

同一题材，三种新尝试。
让作品接受评审。

三个 Agent 各自设计本轮提示词、写稿与制作；第四位 Agent 在匿名、随机排序后比较作品。A/B/C 是任务编号，每次都重新组合表达方式。

共同事实，不同表达

三路共用一份资料、相同质量要求和模型配置。随机的是表达方式，不能随机编造事实。

方案独立，结果可追溯

每位 Agent 只收到自己的约束与公共证据。随机种子、提示词、自评和成片保存在本轮记录。

重试与重新探索分开

失败重试沿用原方案；同题再探索重新抽取组合。随机化不能保证每轮都有不同的赢家。

开场、叙事结构、画面表达、口吻、节奏五个维度分别不重复抽取；避免近期12轮的完整组合。另从4套现有动效模板随机分配3套，模板与 A/B/C 不固定绑定。

  2. 不读取 A/C 的提示词、文稿或自评
  3. 调用同样的配音与渲染能力
  4. 保留自己的创作依据与取舍

  1. 根据第三组随机约束独立构思
  2. 遵守同样的来源与叙事要求

  4. 保留自己的创作依据与取舍

匿名与排序 · 程序执行

隐藏创作者信息，打乱评审顺序

评审收到“版本1/2/3”，不接收 Agent 身份、随机约束、创作提示词和自评。映射关系由程序保留，评审后再对应回原作品。

↓公共证据 + 匿名作品包
独立评审 AGENT

用同一套标准比较，再给出建议

事实与来源 → 叙事闭环 → 具体用途与局限 → 表达清晰度 → 可见画面与场次时序。逐版给出优点、不足、适合人群和对应场次，最后说明推荐理由。

当前评审看抽样帧、文稿与时间线，没有试听音频或观看完整动态。服务不支持图片时明确降级为文字评审。匿名排序减少身份与位置影响，不能消除模型判断中的所有偏差。
↓评审结果映射回 A/B/C；创作者自评另行展示
由你决定

播放比较，多选满意版本入库

查看三条视频与独立评审，可以选择一条、多条，也可以暂时都不选。勾选后保存到成片库；未选成片与此前版本保留，随时可回看。

↓对某一路填写反馈，或对全部路线提出统一要求
SUPERVISOR · 反馈闭环

把你的反馈变成下一轮修改要求

结合原旁白、实际时长与评审结果，为需要重做的路线制定调整方案。单路反馈只重做该路；统一反馈或“三版全部否决”重做全部三路。新版本重新配音、渲染与独立评审，再由你多选入库。

单路反馈 → 指定路线重做全部否决 → 三路重做保留旧视频与反馈记录
反馈重做沿用本轮随机约束，优先落实修改意见。想换全新的开场与表达组合，可以选择“同题再探索”。随机分配由程序完成。

失败如何处理

资料失败 → 停在创作前；一路失败 → 保留其余成片

“上次任务未完成”是历史任务的状态。点击“查看该任务与重试”可查看具体原因。重试仅处理未完成分支；已完成成片保留。评审失败可以只重试评审。
