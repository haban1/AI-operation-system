# 微信群发记录详情（2026-10-23）

在微信机器人管理的「好友群发」页面，点击任一群发记录卡片或右侧「查看详情」打开详情抽屉。

详情包括任务状态、创建及更新时间、任务编号、文字全文、按发送顺序排列的最多三张图片，以及全部接收好友的逐人结果。图片可放大预览，接收好友支持按昵称、备注或微信账号搜索。任务详情每 8 秒刷新，也可以手动刷新。

逐人结果区分已发送、等待发送、发送异常和结果待核对。文字和图片分别显示确认发送情况，图片显示已确认张数；中断或缺失结果不会被当成成功。旧单图记录继续从原任务表读取图片；好友已不在当前通讯录时仍尝试使用保留的联系人资料，没有资料则显示账号。

新增只读接口：

- `GET /api/v1/support/broadcasts/detail?id=<机器人实例ID>&broadcast_id=<任务编号>`
- `GET /api/v1/support/broadcasts/image?id=<机器人实例ID>&broadcast_id=<任务编号>&position=<1..3>`

两者都沿用机器人归属认证，任务编号使用独立参数；图片请求返回原始字节，设置不缓存及禁止 MIME 嗅探的响应头。读取详情不触发发送或改变任务。没有数据库结构迁移。

- admin `go test ./controller -run '^TestBroadcastDetail' -count=1` 通过，检查目标任务/图片参数、响应原样转发和缺少已授权机器人时拒绝转发。
- Swagger 合同与生成的 TypeScript API 已同步；pnpm 8.15.9 lint、TypeScript 检查及生产构建通过。
- 隔离浏览器验证卡片和按钮入口、三图放大预览、搜索、旧图片重试、中断/待发送状态、进度自动更新、错误显示和自动恢复。没有真实群发。
- 部署后核对全部 5 条现有记录及 6 张历史图片；图片 SHA-256 与数据库原件逐张一致，原群发记录的校验和未变；未登录读取被拒绝。
