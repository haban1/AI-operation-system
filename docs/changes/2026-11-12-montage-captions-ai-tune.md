# 2026-11-12：智能混剪文案时间轴、AI 调整合一与模板预览

日期：2026-11-12。基线 `7572fd4`（main）。状态：已在本机 3101 验证，用户要求提交并推送到 main；未部署。

## 背景与目标

用户在 3101 试用智能混剪后指出：

- 文案只能交给 AI 改，或藏在“精细调整”弹窗里；希望文案像镜头一样，能人工修改，也能单独让 AI 微调。
- 首页点模板后看不到模板效果。
- “重新生成部分内容”和“自然语言调整”是两套范围和按钮，逻辑重复；希望合成一处，需要时才展开。
- 部分文字太小、挤在按钮下方，不好操作。

同时要求只保留 3101 环境，只保留一个最新分支。

## 变更与影响

- **文案时间轴（新增 `engines/montage15/public/captions.js`）**：镜头时间轴下方新增“文案”一行，按模板 `cards` 的出现时间（含文字时间偏移）排列开场标题、短句 1、短句 2、收尾短句。点一下会定位到对应时间，右栏切换为文案编辑：
  - 逐项输入并显示字数（开场标题卡含主标题、副标题、署名）。
  - 手动修改通过“精细调整”里原有的输入框事件写入工程，并自动锁定、标记未保存。
  - 可以手动锁定或解锁这段文案。
  - “让 AI 改写这段”提供快捷要求（更简洁 / 更有活力 / 更口语 / 更正式）或自由描述，先解锁这段文案，再以 `fields` 范围只改这一段。
  - “返回镜头”或点镜头回到镜头面板。
- **AI 调整合一（新增 `ai-tune.js`）**：原“重新生成部分内容”和“自然语言调整”合成一个默认收起的“AI 调整”面板，包括：
  - 改哪里：全部未锁定、当前选中的镜头、只改文案、只改音乐。
  - 怎么改（可留空）和一个按钮：留空时为“重新生成”，有描述时为“按描述修改”。
  - 提示文字随范围变化。
  - 执行仍点击隐藏的原 `#ai-regenerate` / `#ai-adjust`，AI 任务、锁定与接口不变。
- **模板预览**：模板运行时的时间轴创建后处于暂停状态，弹窗从未调用播放，所以只看到第一帧。现在弹窗载入后自动播放并循环，加了播放 / 暂停、进度拖动和时间；点封面任意位置都能打开预览。
- **间距**：说明文字由 9–10px、负外边距改为 12px，正常间距；表单标签、锁定选项、输入框放大；预览框去掉粗白边；播放按钮统一为圆形；右栏加宽到 264px。
- **服务器白名单**：`engines/montage15/src/server.mjs` 的静态文件白名单加入 `captions.js`、`ai-tune.js`。
- **环境**：停止 3100 与 3190；3101 工作区切到 `main`，删除已合并的本地分支 `codex/content-creation-main-integration`。3101 用 `scripts/start-montage-local.mjs --restart` 重启，以加载新的白名单。

## 决策与取舍

- 文案编辑复用原输入框事件，而不是另写保存逻辑，保证与“精细调整”、撤销 / 重做、自动锁定一致。
- 合一面板只在前端映射到原有两条执行路径，不改后端范围定义；“按描述修改”时，镜头范围跟随时间轴上当前选中的镜头。
- 本机重启脚本用 `ps` 核对 PID 归属时，非 ASCII 路径会被转义，导致误判“不属于本工作区”；本次以 `LC_ALL=en_US.UTF-8` 运行解决，脚本本身未改。
