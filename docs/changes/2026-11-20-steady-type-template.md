# 稳镜字动：从一次剪辑到可替换素材的模板

## 背景与目标

让操作者用自己的照片和视频复现一条课堂短片的节奏，而不用重做转场或播放烧录了字幕的成片。入口、保存和渲染方式与另外两套业务模板一致。

## 变更与影响

新增 `steady-type`，有全景、讲解、指导、操作、协作、收束六个镜位。每个镜位的字幕都能独立修改和锁定；模板使用 `title`、`beat1` 至 `beat5`，后两条新字段仅对声明它们的模板生效。可替换照片、视频、独立调整配乐和转场音效。既有视频读取自己的模板快照，不迁移已保存修订。

## 决策与取舍

保持素材满幅、镜内构图稳定，通过镜头之间的景别变化而不是连续拉近制造节奏。预览与导出使用同一条可定位时间线，按 128 BPM 对齐节拍。沿用引擎固定的 15 秒、30 帧/秒，支持竖屏和横屏。封面及两条音轨为模板资产；不包含示范课堂素材、成片、商业模板或第三方付费工程。中文字形取决于渲染主机安装的字体。

## 验证与证据

开发时在隔离环境运行以下五个测试文件，27 项通过：模板准入、六段字幕与锁、旧模板拒绝新字段、镜头替换、乱序定位和音轨开关。临时浏览器视频也检查了末两段字幕与锁在自动保存、刷新后保留。

```sh
node --test --test-concurrency=1 test/montage-workbench.test.js test/montage-ai.test.js test/montage-steady-type.test.js test/montage-shot-editing.test.js test/montage-system-planner.test.js
```

隔离工作台曾使用四个视频和两张图片替换六个镜头，实际输出 15.00 秒、1080×1920、30 fps 的 H.264 视频和 AAC 立体声，并抽帧核对六段画面。横屏验证到浏览器/时间线，未单独编码。本段是模板开发时的证据；本次发布快照的复测见[源码交付记录](2026-11-23-github-source-sync.md)。

## 部署与回退

构建 Web 时要同时包含目录注册、编辑代码、海报及两条 WAV。待渲染、AI 编辑及相关任务空闲后再更新服务。要暂时下架，只从业务开放名单移除 `steady-type` 并重载；不要删除旧工程仍需的渲染实现和素材。

## 未完成与下一步

本次模板开发没有调用收费模型或创建真实发布任务。新环境可先用自有六份非敏感素材新建视频，锁定部分字幕，刷新后核对，再全屏查看入库后的最终 MP4。还需实测目标机器字体与横屏编码结果。
