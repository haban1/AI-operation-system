# 隐藏无数据源的运营指标

## 背景与目标

用户要求隐藏总览顶部六张没有数据源的指标卡片。实查曝光量、新增关注、有效引流、活动报名、实际到场、入群目前均由后端固定标记 `PENDING_SOURCE`、值为 null。

## 变更与影响

`public/app.js` 仅渲染状态为 `READY` 且值非 null/undefined 的核心指标；全部未接入时不渲染整排容器，同时移除其“部分指标待接入”说明。有效零值仍可显示，平台实际采集数据、发布量及其他区域保持原行为。后端和接口不变。

## 决策与取舍

按数据状态过滤，保留以后真实接入指标的展示能力；没有全局隐藏提示，也没有移除其他统计模块。只修改局部模板和对应既有测试断言。

## 验证与证据

`node --check public/app.js` 通过；`node scripts/run-tests.mjs --test --test-concurrency=1 test/platform-analytics-ui.test.js` 两项通过、零失败/跳过，覆盖无源指标组不渲染、真实零值/周期日期和筛选迟到响应隔离。正式只读检查中看板与脚本均 HTTP 200，六项全为未接入，展示项为零，服务返回脚本 SHA 与本机修改一致。私有证据在 `.codex-work/hide-pending-kpis-20261110/`。

## 部署与回退

`public/` 为运行挂载，修改已生效，无须重启。用户 Ctrl+F5 刷新即可。回退只恢复本轮前端模板及测试断言；本轮修改前的局部文件备份在上述私有目录，不使用 Git reset 覆盖既有修改，不涉及数据库。
