# 微信收信核查与连接状态提示

日期：2026-11-12（Asia/Shanghai）。状态：前端已修改并应用，未提交、未推送；本轮真实用户测试消息已核对收信和发送记录。

## 背景与目标

用户在微信客服的“人工接待”页看到空会话列表，反馈小助手没有正确启动、没有接收到好友对话。需要区分容器运行、微信账号登录、消息接收和人工接待列表这四种状态。

## 变更与影响

微信前端账号选择栏新增“微信在线 / 微信离线”状态，沿用账号列表每30秒的刷新；账号详情也每30秒刷新，避免登录操作入口长期保留旧状态。人工接待空列表明确提示：普通好友聊天在“联系人”中查看。

代码仅涉及 `src/robot/EmbeddedWorkbench.tsx`、`src/robot/actions/components/RobotDetail.tsx`、`src/customer-support/Reception.tsx`，均位于 `wechat-assistant/wechat-robot-admin-frontend/`。接待状态、消息处理、模型与知识库配置没有因本次前端更改而变化。

## 决策与取舍

核查发现微信此前存在MMTLS解密与自动登录失败，15:45恢复登录。本轮未重新扫码、重启或修改协议，不能把这次会话恢复归因于前端改动。现有人工接待接口只返回active会话；普通聊天没有被人工接管时，空接待列表符合现有功能。

采用状态提示与明确入口说明，不为普通消息自动创建人工接待，以免暂停本应正常运行的AI。账号状态不等于每条消息都已收到，接手时仍需检查具体聊天记录。
