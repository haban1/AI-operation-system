# 2026-11-12：内容创作页外观对齐与流程精简

日期：2026-11-12。基线 `a5561bb`（main，内容创作集成）。状态：已在本机 3101 验证，用户要求提交并推送到 main；未部署。

## 背景与目标

内容创作 Tab 由三层同源页面嵌套组成：创作外框（`engines/video-studio/dist`）、智能混剪（`engines/montage15/public`）、AI 热点（`engines/ai-signal-studio/web`）。集成后功能可用，但：

- 混剪编辑器上方叠了三行标题栏（外框栏目栏、“内容创作 / 智能混剪”品牌栏、工程栏），“内容创作 / 智能混剪”与外框重复。
- 三层各用自己的绿色扁平按钮、方角卡片、深色批量条与深色提示条，和主系统（晨雾 / 夜幕、渐变主按钮、玻璃卡片）不一致；夜间模式下内层仍是旧配色。
- 混剪左栏“素材来源 → 制作要求 → 生成”没有步骤感，“制作要求”标题重复。
- 热点页“单条风格”选择框放在“生成三版对比”之上，说明里又写“上方风格仅用于单条生成”，容易误以为风格影响三版对比。

用户要求联调内容创作 Tab 的交互与风格，并让操作流程更简洁。功能与接口不变。

## 变更与影响

- **新增 `public/creation-skin.css`**：三层页面都引入主系统 `/theme.css` 与此文件，颜色全部取 `--tk-*` 令牌，日间 / 夜间自动跟随。统一主按钮（渐变）、次按钮、文字按钮、输入框、下拉框（上下箭头外观，仍为原生控件）、卡片、状态标签（待确认 = 警示色、可发布 = 成功色）、提示条、弹窗、折叠箭头和分段控件；内层页面背景透明，透出主系统背景。视频画面与模板海报保持原色。
- **创作外框**：顶栏改为与主系统一致的悬浮玻璃工具条：“内容创作” + 分段控件（智能混剪 / AI 热点自动生成 / 成片与素材）+ 服务状态。`.method-nav` 与 `.content-library-link` 原样保留，外面包一层 `.creation-switch`。创作设置视图仍隐藏顶栏。
- **智能混剪**：删除重复的品牌栏，把“已保存 / 保存工程 / 导出视频”并入工程栏，编辑器上方由三行变两行；左栏加步骤编号“① 素材来源 ② 制作要求”，隐藏重复的“制作要求”标签（读屏仍可读）；按钮 ID 与事件不变。
- **AI 热点**：栏目改为分段控件；“生成三版对比”作为主操作放在前面，“只要一条？选个风格直接生成”把风格选择与“生成单条”放在同一组；`#style-select`、`#build`、`#compare` 的 ID 与逻辑不变。创作设置视图仍隐藏栏目。
- **主系统**：`hot-topic-studio.css` 让嵌入容器透明；更新 `hot-topic-studio.js`、`app.js`、`index.html` 中的缓存版本号。

后端、接口与各页面脚本均未改动。

## 决策与取舍

- 用一份共享样式覆盖三层，而不是分别改三个引擎的原样式，便于以后统一调整；代价是较多 `!important`，以压过各引擎原样式。
- 下拉框只改外观，不接入主系统的 `ui-select` 组件：内层脚本多处直接给 `select.value` 赋值，替换组件可能出现显示与取值不一致。
- 保留各层原有路由与消息协议，只调整 DOM 位置与样式。
