# 发布安全验证与人工确认核验

部署日期：2026-10-29。入口：智慧驱动 → 发布管理 → 发布任务。

## 使用流程

1. 自动发布遇到平台验证码、安全验证等人工操作时，任务显示 **待人工安全验证发布**，保留原浏览器页面和当前素材。
2. 点击 **打开平台处理**，在原平台完成验证并完成发布。
3. 回到智慧驱动点击 **我已发布，开始核验**。此时任务先显示已提交、待核验。
4. 系统自动读取平台作品管理页。确认发布后显示已发布；审核中继续跟踪审核状态；暂未确认结果时继续只读核验。

等待安全验证期间，该平台暂停自动领取任务和定时登录检查，避免跳转覆盖验证页面。人工确认会锁定投稿并取消旧的排队发布任务，仅安排结果核验。重复点击确认不会重复排队或重复投稿。

## 实现

- `src/services/publish-manual-verification.js` 统一识别平台安全验证结果。
- 通用发布适配器和抖音适配器在登录检查、发布准备和提交后均可进入等待人工状态。
- 数据库沿用 `NEEDS_CONFIRMATION`，通过 `manualSecurityVerificationRequired` 区分安全验证等待；界面显示专用文案和人工安全验证步骤。
- 人工确认接口将任务设为 `SUBMITTED` 并锁定投稿，排入一个 `VERIFY_PUBLISH`；平台核验结果更新最终状态。
- 旧安全验证失败记录启动时转为等待人工；旧版直接标成功且带 `PUBLISHED_ON_PLATFORM` 标记的人工记录转入只读核验。其他已发布记录保持原有处理方式。
- 普通素材和网络故障仍按原有错误处理。
