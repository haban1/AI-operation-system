# GitHub 源码仓库说明

仓库：<https://github.com/haban1/AI-operation-system>

本次发布为 2026-10-20 当前工作目录的完整源码快照，包括尚未提交到原开发仓库的修改。仓库根目录对应交接包中的 `project/`。

包含天河 Web、Local Agent、RAG、8080 微信机器人客户端与管理后台、容器配置、配置模板、测试、示例素材和开发文档。微信人工接待、好友群发、群运营、朋友圈定时发布及 AI 内容计划均包含在内；8000 客服服务源码作为历史实现保留，当前运行架构不启动该服务。

旧开发仓库的历史包含真实业务数据库，因此本仓库从经过检查的源码快照开始，不携带旧 Git 历史。本机开发目录及其原有 Git 历史保持不变。

以下内容不在源码仓库内：

- 实际 `.env` 文件、登录密钥、API Key、数据库密码及证书。
- 业务数据库、微信登录状态、浏览器会话、知识库上传原件、索引、模型缓存、日志及备份。
- 依赖目录、编译产物、安装包、临时文件、旧差异补丁和首次登录信息。

部分配置模板、测试和历史演示代码保留明确的开发示例值；这些值不适用于正式部署。旧微信 Compose 模板中的数据库密码已改为从 `MYSQL_ROOT_PASSWORD` 环境变量读取，需在对应部署目录的 `.env` 中提供。
