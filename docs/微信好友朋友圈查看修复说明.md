# 微信好友朋友圈查看修复（2026-10-23）

入口：微信机器人管理 → 联系人 → 朋友 → 好友行的更多菜单 → 朋友圈。

## 原因与行为

微信用户页接口会用 `BaseResponse.ret=207/2001/2004` 配合 `RetTips` 返回最近一个月、半年或三天的可见范围。本次真实请求确认这三个状态均带有可见范围提示。原客户端把它们作为通用错误，管理后台收到 500，用户无法正常查看好友页。

现在仅在好友朋友圈用户页接口，对这三个状态且含非空 `RetTips` 的响应保留页面内容和提示。其他接口的错误判断不变；未知状态、登录失败、HTTP 错误和不完整响应仍报错。请求最长等待 30 秒。

页面展示微信返回的可见动态及范围说明，无内容时显示“暂无可见的朋友圈”；失败时提供重试，右上角提供刷新。加载更多按原始字符串 ID 去重并更新已有动态，刷新重新获取第一页，避免刷新后残留旧数据。仅按游标推进或空页判断结束，不再用固定 10 条判断。

## 验证与部署

- `go test ./pkg/robot -run '^TestFriendMoments' -count=1`：正常页、三个可见范围状态的空页/有内容页、完整 64 位 ID、请求目标及游标、异常响应均通过。
- 前端 pnpm 8.15.9：lint、TypeScript、生产构建通过。
- 隔离浏览器：好友菜单入口、内容、单条详情、可见范围空页、翻页去重、刷新重置、失败重试均通过；没有调用真实发送/发布/点赞/评论。
- 部署后通过 8080 认证接口检查了 5 位好友，均返回成功及可见范围提示；微信在这些请求中均未返回可见动态。线上前端与测试构建一致。
- 更新机器人 client 和 UI；账号保持在线，微信协议容器未重启；设置及资料数量未变。
