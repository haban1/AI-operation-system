# 朋友圈定时发布与 AI 内容计划

2026-10-20 已部署到现有 8080 微信机器人模块。入口：天河工作空间的微信模块 → 管理机器人 → 朋友圈 → **发布计划**。如果页面仍是旧版本，请刷新。

## 定时发布

点击“新建定时发布”，填写计划名称、正文、附件、发布时间、可见范围和提醒好友，然后保存。可只发文字、图文或视频。此方式为单次发布。

- 最多9张图片，每张不超过10MB；或1个不超过30MB的视频。
- 附件合计不超过40MB，图片和视频不能混合。
- 附件原文件保存在机器人实例数据库，发布时才上传微信，避免依赖提前上传后可能失效的地址。
- 可见范围支持公开、仅自己可见、部分好友可见、不给指定好友看。

## AI 内容计划

点击“新建 AI 内容计划”，填写主题和写作要求，可选微信模块现有的原生知识库，设置单次、每天或每周执行，以及首次发布时间。

发布方式有两种：

1. **审核后发布（默认）**：先生成文案，在“待审核”或“执行记录”里点击“审核文案”，修改正文、确认未来发布时间，再安排发布。未审核的文案不会发布；错过原时间后需要重新选择未来时间。
2. **自动发布**：保存计划后，系统生成文案并在指定时间和可见范围内发布。

模型使用机器人现有全局配置，当前已连接天河统一模型网关。无需填写新的模型密钥。知识检索复用 8080 原生知识库及索引；选择知识库却没有检索到资料时，记录失败原因，不使用无依据文案继续发布。未选择知识库时根据主题创作。

首次文案在创建计划后进入生成队列。后续审核文案提前一天生成，自动发布文案提前30分钟生成。模型不会自动绘图；可以给计划附上固定图片或视频，周期计划将重复使用这些附件。

模型生成正文会去掉 Markdown 展示标记，避免此前大量星号的问题。AI 仍可能生成不准确的表述，需要逐条审核时应选择审核模式。

## 计划和执行记录

- 时间按创建时浏览器的时区保存；每天或每周保持该时区的本地时间。执行记录的时间按查看者浏览器时区显示。
- “暂停”会取消该计划尚未发布的任务；“恢复”从尚未生成过的下一个周期继续，不恢复已取消任务。
- “取消计划”停止整个计划；“取消任务”仅取消当前这一条，周期计划后续仍继续。
- 单次计划显示“已生成单次任务”后，实际发布结果应到“执行记录”查看。
- 发布结果不明确时显示“结果待核对”，不会自动重试，周期计划会暂停。先在手机微信核对，再决定是否创建另一条或恢复后续周期。
- 服务离线或重启不会丢失计划。机器人离线时任务等待；超过计划时间1小时的任务标记过期，不集中补发。
- 页面展示最近200条计划及200条执行记录，数据库仍保留历史记录。
- 生成或上传过程异常中断超过30分钟后标记失败；发布过程异常中断超过30分钟后标记待核对。

保存前会在浏览器保留本次提交编号。若网络响应丢失，可通过“核对并恢复本次提交”用同一编号核对，不会重复创建计划。清除浏览器提交记录不等于取消服务端计划。
