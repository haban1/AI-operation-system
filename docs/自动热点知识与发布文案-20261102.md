# 自动热点知识与发布文案

自动热点生成的成片进入共享素材库时，系统从该次生成的 `script.json` 实际旁白、来源及可核对的研究引文整理配套 Markdown 知识文档。文件保存在素材库私有 `knowledge/` 目录，绑定素材 ID、视频 SHA256 和文档 SHA256。素材列表和发布草稿接口不返回知识正文。

选择此成片去发布时，标题和正文自动带入发布表单，仍可人工修改，仍须经过原有素材预检、AI 审核和发布确认。发布用标题不超过 20 个字符。修改发布文案不改变已固定的视频知识文档。

用户确认且**发布任务创建成功**后，知识入库任务与视频发布任务在同一数据库事务中保存。仅批准素材、打开发布草稿、预检失败或任务创建回滚都不触发知识入库。定时发布在到点创建正式发布任务时触发。该规则包括普通草稿执行模式，不以平台最终发布成功为前提。

后台知识任务独立执行：上传文档、等待处理完成、基于当前正式知识版本进行 PRE_RELEASE 增量测试、验证回答确实引用该视频文档，再发布并确认当前正式版本包含此文档。保留已有知识成员及禁用记录。重复确认复用同一任务；网络异常退避重试，进程重启可恢复，知识处理等待不阻塞视频执行。

正式知识服务使用现有 `RAG_BASE_URL`、`RAG_ADMIN_ENABLED`、`RAG_KNOWLEDGE_BASE_ID` 和管理员凭据，无需新增模型配置。未启用服务时仍保存入库任务，服务配置恢复并重启后继续执行。处理失败或来源验证失败会保留任务错误，不能视为已正式入库；禁用内容冲突进入待复核。禁用文本检查采用规范化文本匹配，不能替代语义审核。

旧视频若保留对应生成旁白，可在同步时补齐私有文档；仅剩视频或标题的历史素材不会凭空生成知识。丢失的私有副本只允许从与原文档哈希完全相同的来源资料恢复。普通上传、素材剪辑、AIGC 创作和微信客服流程沿用原有行为。

开发验证：`test/hot-topic-document.test.js`、`test/hot-topic-library.test.js`、`test/hot-topic-knowledge.test.js`、`test/hot-topic-publish-integration.test.js`、`test/hot-topic-publish-payload.test.js`。测试使用隔离资料和数据库，不发布真实视频或向真实知识库加入测试内容。
