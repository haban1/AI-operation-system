# 微信聊天图片预览

2026-10-23 已部署到本机 8080 微信机器人后台。

## 使用

在微信模块的「联系人 → 聊天记录」中直接显示图片，点击图片可放大、缩放、旋转和下载。图片暂时不可用时显示说明和「重新加载图片」，不再只显示破损图片占位符。外部图片链接失效时，会尝试读取机器人保存的图片。

## 保存与读取

- 普通图片发送（包括好友群发）成功后，保存原始图片到机器人实例库的 `message_images`，以聊天消息 ID 关联。
- 分片发送使用 `message_image_chunks` 暂存分片，成功发送后按偏移组装并保存，随后清除分片；新上传开始时清理超过 24 小时的遗留分片。保存上限为 50 MiB。
- 收到的图片首次查看时从微信 CDN 下载并缓存；后续优先使用数据库中的图片。首次下载前已失效、且没有本地副本的图片无法恢复，会显示加载失败提示。
- 图片数据与聊天列表分表，列表接口不返回二进制文件。数据保存在 MySQL 数据卷，重新创建客户端容器不会丢失。
- CDN 转发图片保留原有 XML；发送回执补充已有图片记录的 XML，不重复处理消息或触发人工接管。
- 发送已成功后，图片保存失败只记录错误，不把发送标为失败，不自动重复发送。
- 图片预览继续通过管理后台原有登录认证和机器人归属检查，未开放匿名图片接口。

## 本次历史恢复与验证

原有 13 条图片记录中，10 条由机器人发送的图片没有保存附件或 CDN 信息。按群发任务的接收人、本机记录时间、成功结果和图片发送顺序核对后，从已有群发附件恢复了这 10 条图片；每张均校验 SHA-256 与原文件一致。

部署后通过带登录会话的 8080 图片接口检查：13 条图片全部返回 HTTP 200 和有效图片类型。页面隔离测试验证缩略图、点击放大、失败后重试，以及外部链接失效时回退到本地保存内容。测试未向微信发送任何消息。
