# 评论单轮判断与视频知识短问法

## 行为

- 评论只判断当前一条，不带历史用户消息或历史 AI 回复；已验证的所属作品标题仍可用于识别咨询对象，不能作为答案依据。
- 评论没有可靠知识时直接转人工，不反问。私信保留原来的历史会话与澄清规则。
- 视频知识仍只根据音频转写生成。FAQ 的完整问题保留业务名称，并在同一问题的括号内附上少量同义短问法；答案明确业务对象、条件和步骤。
- 原文涉及多个业务、短问法可能对应不同答案时，不生成省略对象的裸短问法。不为原文未讲解的问题补写答案。

## 门槛配置

配置在安装目录的 `rag-service/.env`，修改后重启 RAG 服务；平台根目录 `.env` 中同名项会优先传入服务。

```dotenv
RAG_EVIDENCE_MIN_SCORE=0.38
# 可选，未设置时各自继承上面的共享值；以下数值仅示范原默认门槛：
RAG_COMMENT_EVIDENCE_MIN_SCORE=0.38
RAG_DIRECT_MESSAGE_EVIDENCE_MIN_SCORE=0.38
```

数值范围为 0–1，越高越严格。此次没有改变实际部署配置，也没有默认降低门槛。需要根据真实检索记录决定是否调整评论门槛，私信可保持原值。

这两个配置控制 RAG 证据检查，作用于检索返回的候选得分，不会凭空提高得分。没有候选、已有知识冲突、缺少具体依据、答案没有有效引用或超长时，原有拒答规则仍适用。独立门槛也不会绕过上游检索筛选。

`evidence.gate` 检索跟踪以及调试结果中的 `evidenceGate` 会记录 `channelType`、实际 `threshold`，有候选时记录 `topScore`。界面转人工后显示的置信度 0 不是检索原始得分。

## 现有视频知识如何生效

新的生成规则只影响新生成或重新生成的草稿，不会自动改写已经审核发布的知识。现有视频知识需要重新生成草稿，核对音频事实及常见问法，加入知识库、测试并发布后，正式评论才会使用新内容。重新生成需原视频仍可访问，且会调用在线 AI。

小智测试默认按私信渠道运行，可验证新知识是否能回答短问法；它不验证评论独立门槛。评论门槛应通过评论渠道的 RAG 调试请求或真实评论记录验证。

## 本地验证范围

离线测试覆盖：同一候选在两个渠道分别按配置通过或拒答；共享配置向后兼容；非法数值拒绝；评论历史被隔离而私信保留历史；无候选、知识冲突仍拒答；带简短问法的 Markdown 知识能够进入本地索引并召回；生成请求要求业务明确且答案以音频为依据。

模型每次生成的措辞、另一台电脑的知识内容及真实评论效果，仍需该环境验证。本次不重打安装包。
