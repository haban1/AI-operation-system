# 微信群成员自动同步

在机器人管理后台的「联系人 → 群聊 → 查看群成员」中，每次打开都会先向微信核对完整成员名单，再加载本地分页列表。默认显示「当前成员」，可切换查看「已退群」。每位成员显示头像和群昵称；群昵称与微信名不同的时候同时显示微信名。

同步失败、微信返回空名单、群 ID 不匹配、成员数量不完整或成员 ID 重复时，保留原记录并显示错误，可点击「重新同步」。失败时不展示旧名单为最新结果。微信未返回昵称或头像时，保留已有资料；头像优先小图，缺失时采用大图。

同步在事务内更新新成员、退群和重新入群状态，保留积分、黑名单和管理设置。搜索条件限定在当前群与所选成员状态内。查看页面的同步不发送群内退群通知；后台群事件继续遵循原来的通知配置。

验证覆盖：完整及异常协议响应、退群与重新入群、资料更新、成员设置保留、事务回滚、跨群搜索隔离、管理端错误传递，以及浏览器首次打开、再次打开、头像加载、退群列表、失败重试。

本次部署的镜像标签为 `group-members-20261023`，部署前镜像备份为 `before-group-members-20261023`。群数据及验证结果位于本地 `backups/wechat-group-members-20261023/`，该备份含业务数据，不应提交到远端仓库。

部署后已核对一个实际微信群：微信返回 4 位当前成员，本地当前成员也为 4 位，均有名称与头像；另有 1 条退群历史。成员设置保留，账号在线，微信协议容器未重启。
