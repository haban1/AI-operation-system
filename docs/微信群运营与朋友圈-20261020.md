# 微信群运营与朋友圈配置（2026-10-20）

用户选择：指定微信群启用欢迎语、群聊总结、每日早报；朋友圈自动点赞、评论手动。具体微信群由用户以后自行选择。

## 已保存的配置

| 功能 | 配置 |
| --- | --- |
| 每日早报 | 总开关开启，文字形式，每天北京时间 08:30；尚未选择发送群 |
| 群聊总结 | 总开关开启，文字形式，每天北京时间 09:00 总结前一天；尚未选择发送群 |
| 欢迎语 | 模板“欢迎加入，有问题可以在群里交流。”；全局默认关闭，由具体群单独开启 |
| 朋友圈点赞 | 已开启，沿用每 120 分钟同步一次；由模型判断适合点赞后执行 |
| 朋友圈评论 | 自动评论关闭，在页面手动评论 |
| 模型 | 朋友圈工作流使用 tianhe-robot-chat，图片/视频使用 tianhe-robot-vision，群总结使用 tianhe-robot-summary；通过天河统一网关调用 |

当前联系人已同步，群列表和群运营配置均为 0。没有给所有群开启欢迎语，也没有向任何群发送测试内容。以后新增群也需要单独启用群运营。

## 以后选择群

1. 进入天河“微信客服”，点击“管理机器人”。
2. 在“联系人”中选择群聊，打开目标群的设置。
3. 开启该群的“群聊总结”和“每日早报”，使用全局时间及文字模式。
4. 欢迎语可点击“使用全局配置填充群聊欢迎新成员设置”，然后开启“欢迎新成员”，保存。

如果群不在列表中，在手机微信将该群保存到通讯录后同步联系人。机器人必须在该群内。未保存到通讯录的群，也可在有新群消息被机器人接收后出现在后台。

原生群总结逻辑要求前一天至少 100 条可统计消息；不足时发送活跃度不足提示，不生成完整总结。本次未修改该规则。时间在“全局设置”里修改。

朋友圈设置位于“管理机器人 → 朋友圈 → 朋友圈设置”，可以修改同步间隔、自动点赞开关、白名单与黑名单；目前未增加名单限制。

## 已验证及限制

- 早报接口可用，返回 2026-10-20 的 15 条新闻；定时任务注册成功。
- 朋友圈工作流使用 JSON object 模式，适配当前天河模型；模拟“感冒发烧”动态得到不点赞、可评论的判断。
