# 平台运营数据接入（2026-11-02）

已接入账号概览数据的读取、入库与展示。公开记录省略实际账号、标识与读数；仅采纳来源和身份均通过核验的指标，无法确认的字段保持空缺。

## 运行方式

- Web 在 `five_platform_assisted` 模式默认启用，可用 `OPERATIONS_ANALYTICS_ENABLED=false` 关闭。
- 每分钟检查是否具备采集条件；同一账号自动采集至少间隔 30 分钟。手动“采集平台数据”最短间隔一分钟，已有排队任务直接复用；业务忙时先排队，空闲后读取。
- 仅采集已启用、已登录且运行中的平台，复用当前浏览器登录状态。小红书本轮未启用。
- 采集走低优先级 `COLLECT_ANALYTICS` 任务，避让同平台可执行的发布、核验、私信、评论和回复任务。
- 使用独立临时标签页，总限时 25 秒；采集完关闭该页及其弹窗。不会导航原有发布或互动页面。
- 首页每 30 秒刷新显示；点击“采集平台数据”只创建读取任务，不执行发布或发送消息。

## 数据核验

`platform_analytics_snapshots` 独立保存账号、来源、指标、采集时间及受限页面证据，不写入知识库、互动消息或发布表。

- 只接纳已验证身份的账号概览/数据页面。作品列表的单条视频数字、信息流中的其他作者数字均排除。
- 优先匹配账号已有平台 ID/昵称；未绑定身份的账号建立本模块首次采集基线，不改动账号表的绑定字段。
- 每次领取有独立 token；取消、租约过期、旧尝试回调、账号停用、Profile 更换均不能写入快照。
- 缺少指标保留空缺，真实零值显示为零。同一指标的口径、周期或数字冲突时拒绝该指标，不求和。
- 增长类指标必须有明确周期；累计粉丝继续按快照展示。页面日期按上海时区显示。
- 本机浏览器目录名与数据库逻辑 Profile 不同，因此 Windows supervisor 显式配置 `PLATFORM_ANALYTICS_PROFILE_BINDINGS`。切换本机 Profile 配置时应同步维护此映射。
- 证据不包含 cookie/token，大小最多 8 KiB，每页正文摘录最多 600 字。页面仅返回统计及安全的采集状态，不返回原始证据。

## 验证

`npm run test:analytics` 运行服务、调度、采集器、入库和界面测试。界面测试在已安装 Chrome 时验证真实零值、上海日期与迟到响应隔离。

本次同时验证原视频素材/发布、自动热点知识入库、微信代理及模型网关相关回归。现场验证只读取数据，不另行发布内容、发送消息或填充知识库。
