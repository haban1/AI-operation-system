# 天河 AI 数字员工平台整体项目使用说明

> 版本：0.1.0　构建日期：2026-08-14　适用：Windows 10/11 64 位

## 1. 项目概述

天河 AI 数字员工平台是一套运行在 Windows 本机的五平台内容运营与互动自动化 MVP。系统以 Web 管理端统一控制小红书、抖音、视频号、B站和微博五个平台；每个平台使用独立浏览器 Profile、独立运行开关和独立执行门禁，共享任务中心、知识库、AI 审核、企业微信通知、问题汇总与审计机制。

当前交付属于可运行的技术验证版，不应直接视为无人值守生产系统。真实平台页面、账号权限和风控规则可能变化，首次启用真实账号时应使用测试内容并进行人工监护。

## 2. 安装包与运行环境

支持系统：Windows 10/11 64 位。安装包自带 Node.js 运行时、Chrome 运行文件、FFmpeg、ffprobe 和程序依赖，普通使用不需要另行安装 Node.js。

默认安装目录：%LOCALAPPDATA%\TianheAIDigitalEmployee。默认 Web 地址：http://127.0.0.1:3100；Local Agent 地址：http://127.0.0.1:17831。服务仅监听本机回环地址。

安装包不包含真实平台账号密码、Cookie、验证码、API Key 或开发环境配置。各内容平台必须由使用者在独立浏览器 Profile 中人工登录。

## 3. 安装、卸载与后台登录

1）双击 Tianhe-AI-Digital-Employee-Setup-0.1.0.exe，按向导完成安装。

2）安装程序首次运行 initialize-mvp.ps1，自动生成 .env、data、logs、outputs、tmp 等目录；内部 Agent Token 和加密密钥随机生成。

3）管理后台账号固定为 admin，密码固定为 admin123。安装目录中的“首次登录信息.txt”也会记录本机访问地址和该后台账号。

4）桌面快捷方式“天河AI数字员工平台”用于启动；浏览器访问 http://127.0.0.1:3100。

5）可从 Windows“设置 → 应用 → 已安装的应用”卸载，或运行安装目录中的“卸载天河AI数字员工平台.exe”。卸载时可选择保留或删除业务数据库、平台登录状态、配置和日志。

## 4. 首页与主要功能

运行总览：查看五个平台、任务、账号、设备、Local Agent、异常和待人工确认状态。

平台启停：管理全局运行开关、五个平台独立启停、账号启停、智能回复、登录状态和 RPA 设备；“一键打开已开启平台”会先启用有效账号与平台，再显式打开各平台登录页。

内容发布：选择本地素材，执行格式预检、AI 内容/画面审核，创建多平台发布任务。

任务中心：查看发布、采集、回复等任务的排队、执行、成功、失败和 NEEDS_CONFIRMATION 状态。

评论与私信：查看采集消息、自动回复判断、知识不足、风险转人工和人工处理状态。

知识库：管理公共知识库以及五个平台专属知识库；公共知识可供五个平台使用，平台知识只允许对应平台调用。

问题汇总：集中查看 AI、知识、RPA、登录、发布、回复等异常，并提供 AI 自检、人工已处理、误判和安全重试操作。

企微及 AI：配置企业微信机器人、千问模型及 Key，并查看 AI 调用日志。

## 5. 五平台安全启用顺序

平台默认安全关闭。正常顺序为：①登录 Web 后台；②打开全局运行开关；③启用目标平台账号；④开启目标平台；⑤点击该平台“打开登录”；⑥在独立浏览器中人工登录；⑦执行登录检查；⑧再创建发布、采集或回复任务。

未登录 Web 后台、未启用账号、未开启平台或未点击“打开登录”时，不轮询对应平台，也不会因为其他平台已打开而唤醒。需要批量操作时，可在运行总览点击“一键打开已开启平台”；该操作会显式打开登录页，不是后台静默轮询。

停止单个平台会阻止其新任务领取、自动登录检查和消息采集，关闭该平台受控浏览器并按独立 Profile 清理残留浏览器及子进程。关闭全局开关、停止 Web 或运行停止脚本时，会停止全部轮询并关闭全部受控平台进程。

## 6. 内容发布操作

1）进入“内容发布”，填写标题、正文和内容来源。

2）选择本机素材。素材原文件不会上传到 Web 服务，系统只保存路径、元数据、审核摘要和必要证据。

3）选择目标平台账号并执行分平台素材预检；阻断项必须修复，警告项需要人工核对。

4）确认页面中的图片或视频可以正常预览，再执行 AI 内容与图片审核。视频审核会通过 Local Agent 从本机素材抽取代表帧；原始视频不上传到 Web 服务。警告需人工确认，阻断项不能放行。

5）提交后在“任务中心”查看每个平台的独立执行结果。“已提交”不等于“平台已发布”，应以平台成功证据或人工核对为准。

6）发布结果不明确时不要直接重复发布，应进入“问题汇总”完成 AI 自检或人工核对，避免重复投稿。

## 7. 评论、私信与智能回复

智能回复必须在“平台启停”中按平台单独开启。账号停用、平台停止、全局开关关闭、登录不可用或存在活动问题阻断时，回复任务不会被领取或发送。

系统只对满足精确来源、稳定身份、知识依据、风险规则和发送证据的消息自动回复；投诉、转人工、知识不足、目标不唯一和结果不明确等情况转人工。

人工回复或外部已处理后，应在问题列表或消息列表标记处理状态，系统会取消对应的自动回复路径，避免补发。

## 8. 知识库与 Excel 导入

知识库支持固定大类、小类、问题、标准答案、关键词、风险等级以及平台隔离字段。公共知识五个平台共享；平台专属知识只允许对应平台的 RPA 检索。

交付包“04_知识库Excel”内含当前知识库完整导出、五平台隔离测试总表及五个平台单独 Excel，可直接用于导入和数据清洗测试。

导入前建议先备份数据库。导入后检查重复问题、空答案、异常空格、全半角符号、平台字段、风险等级和超长文本，再进行知识预审核。

## 9. 问题汇总与 AI 自检

发布、回复、采集、登录或其他运行失败时，系统会创建问题并对精确任务、账号、平台功能、平台或系统范围实施阻断，避免错误持续扩大。

AI 自检 V1 只读取证：不点击、不输入、不提交，不修改代码或定位器，不自动发布、回复或补发；它只检查问题关联的平台和账号，未开启平台绝不唤醒。平台或 Web 关闭后，自检会安全取消。

AI 自检会给出分类、失败阶段、置信度、页面变化判断、证据和建议。结果不明确、可能已发生写操作或本地安全规则不允许时，必须人工确认，不能安全重试。

“人工已处理”用于确认工作人员已完成处理并释放本问题阻断；“误判”用于确认问题不成立。只有自检明确确认安全且服务端门禁允许时，才可点击“安全重试”。

## 10. 数据库导出与迁移

业务数据库为 SQLite，默认位于 data\mvp.db。交付包提供一致性备份数据库、完整结构与数据 SQL、全表 JSON、逐表 CSV、表清单和迁移说明。

迁移建议：①停止旧机器平台和 Web；②备份旧安装目录；③在新机器安装相同版本；④停止新安装程序；⑤复制 .env（如需保留配置）、业务数据库和必要 browser-profiles；⑥重新启动并核对账号、平台、知识库和问题列表。

平台登录状态和 Cookie 属于敏感数据，是否迁移 browser-profiles 应由账号负责人决定；跨机器迁移后平台可能要求重新扫码、验证码或人脸验证。

## 11. 启动、停止与故障排查

启动：运行桌面快捷方式或 start-mvp.cmd。停止：运行“停止天河AI数字员工平台”快捷方式或 stop-mvp.cmd。停止流程会先请求 Local Agent 安全关闭，再结束 Web。

无法打开页面：检查 3100 端口以及 logs\server.err.log、logs\server.out.log。Local Agent 离线：确认全局运行开关并检查 17831 端口及 Agent 日志。

平台不能执行：依次检查后台是否已登录、全局开关、账号是否启用、平台是否 RUNNING、是否点击打开登录、登录状态、设备在线状态和活动问题阻断。素材上传后无法播放或 AI 无法检测时，先重新选择文件并确认 Local Agent 在线；预览地址会自动使用当前 Agent 端口。

任务出现 NEEDS_CONFIRMATION：不要从旧重试入口绕过问题闭环；请进入“问题汇总”执行 AI 自检并按证据人工处理。

## 12. 安全与隐私

系统不保存或自动填写平台密码、短信验证码、扫码、人脸验证信息，也不提供验证码绕过、指纹伪造、WebDriver 隐藏、代理轮换或其他规避平台风控的能力。

安装包中的 admin / admin123 仅为本机 Web 管理后台账号，不是任何内容平台账号。各平台账号密码不在安装包、知识库 Excel、数据库迁移说明或使用文档中提供。

如需对外网开放 Web 管理端，应在正式部署前增加 HTTPS、反向代理、网络访问控制、密钥轮换、集中审计、异机备份和外部监控；当前默认仅供本机访问。
