# 前端操作与功能入口

顶栏分段按钮切换当前模块栏目，侧栏搜索或 Ctrl+K（Mac 为 ⌘K）可快速跳转。左下角“AI 员工”卡可展开原运行开关；账号登录失效时在“平台账号”重新登录，平台开启不等于已登录。

左侧选择模块，页面顶部切换栏目；次要配置、明细和技术信息按需展开。以下为 2026-11-12 的当前入口；知识库保留文件增删改查，并提供人设配置与本地 RAG 测试，不再使用原审核、发布或回退接口。

## 内容创作

本轮 3101 内容创作集成基于 main `88907a5`，顶部直接显示“智能混剪、AI 热点自动生成”，
默认进入混剪模板与最近工程。右上角“成片与素材”管理跨来源结果，保留预览、下载、
确认可发布和去发布。创作设置继续在系统设置，切换时保留嵌入工作台及输入。
这是本地联调入口，未正式替换既有 3100 环境，实际验收边界见
[联调记录](changes/2026-11-12-content-main-integration.md)。

| 创作入口 | 功能与位置 |
| --- | --- |
| 智能混剪 | 透视穿梭、棱镜脉冲两套模板，最近工程，文件夹索引，AI 选片，原片预览、指定入点与镜头替换、自然语言局部修改、15 秒预览与导出；对应 `#editing` |
| AI 热点自动生成 | 热点选题、自主选题、成片对比、成片详情；来源、证据、研究方式及讨论线索按需展开；保留单条/三版生成、选入库、评审、反馈重做、文稿修改与下载；对应 `#automatic/create` |
| 成片与素材 | 按来源/确认状态筛选跨来源共享成片，预览、下载、批量或单条确认、带入发布；对应 `#materials` |

智能混剪先选模板并新建工程，再复用或连接素材文件夹。进入工程后，左侧是素材来源、制作要求和素材预览，
中间是成片预览与镜头时间轴，右侧调整选中镜头。署名、图层、声画偏移等放在精细调整中。
自然语言只修改明确指定的镜头或类型；默认沿用模板原配乐。详细流程与验收见
[制作版体验验收](智能混剪-制作版体验验收.md)。旧会话接口保留兼容，默认制作入口使用新混剪面板。

成片仍区分“待确认”和“可发布”，发布页素材选择器继续使用共享成片库。自动成片内的“成片库”进入原热点成片集合，历史链接仍有效。

## 发布、知识和系统设置

- **发布内容**：按“编辑内容 → 选择平台 → 检查并发布”三步操作，每次只展示当前步骤，底部通过上一步、下一步继续；顶部步骤可直接返回核对，切换发布排期也保留草稿。第一步选择素材、编辑标题/正文和内容来源；第二步选择可用账号，不可用账号和原因可展开；第三步核对摘要、预检与 AI 审核，选择创建草稿或明确勾选自动提交后立即/定时发布。默认不授权自动提交，风险警告仍须确认，阻断项和审核失败不能放行。本机路径可展开，素材库带入、AI 文案、失败重试沿用原功能。
- **发布排期**：单独查看未来安排与发布记录，保留创建、取消、倒计时、失败原因和进入正式任务；实际任务仍由原后台执行。**发布任务**保留各平台结果、核验、重试和待确认状态。
- **知识库**：文件管理提供上传、搜索、查看、替换和删除，处理完成自动生效，无需审核或发布。“回答风格 / 人设”保存助手名称、组织名称、人设要求和问候语；“RAG 问答测试”使用当前知识与已保存人设，支持连续追问、来源查看及清空对话，只在本地展示。版本回退、问法、自定义转人工说法和旧审核工作流不恢复。操作与接口见 [知识库文件管理](knowledge-files.md)。
- **AI 服务**：模型配置与服务状态两栏，高级模型等配置可展开，保存和连接测试仍在。**消息通知**单独展示原通知配置及记录。**调用记录**查看原费用、调用与失败记录，趋势图按需展开。
- **创作设置**：从系统设置的同名栏目进入，主系统地址为 `#creation-settings`。原模型和配音配置页面整体复用，保留服务/模型/密钥、Edge/语音 API/离线配音、保存、连接测试和试听，输出说明可展开；进入该页时不展示创作与热点导航。工作台旧 `#settings` 链接在嵌入主系统时转到此入口，原保存接口不变。
- **浏览器状态**：逐账号显示最近检查正常、需要登录、需要验证、连接中断或待检查；已暂停、未运行和未接入不算故障。点击“怎么修复／查看帮助”打开简短步骤，可前往平台账号登录或查看问题记录。页面沿用五秒状态轮询，“刷新状态”重新读取现有状态；这些操作不会自动重启、改开关或重新发送任务。原浏览器命令、设备信息和检查记录保留在默认折叠的“维护详情”中。

## 微信客服

微信工作区保留人工接待、好友群发、联系人、朋友圈、人设管理、知识库六个业务标签，以及“设置”入口。

- **人工接待**：左侧真实会话队列，右侧显示选中会话的最新消息；接待设置在抽屉中，原因和会话标识可展开，保留恢复 AI、主动接管、通知错误与确认步骤。当前 API 只提供最新消息，人工回复仍在微信客户端完成。
- **好友群发**：内容编辑与接收人两栏，好友用复选列表选择，群发记录在抽屉；保留文字/图片、预览、确认、请求编号、防重复锁和结果核对。
- **联系人**：紧凑行式列表，保留好友/群/公众号、搜索、分页、消息、设置和聊天记录。**人设管理**采用正文与人设列表两栏，保留搜索、新建、编辑和删除。
- **朋友圈/知识库**：继续使用原完整组件和原发布计划、文本/图片资料管理功能。

“设置”按以下八项进入原功能：

| 设置入口 | 原有功能 |
| --- | --- |
| 微信账号 | 原完整账号管理；账号/设备/实例详情、登录/退出、状态刷新及容器/镜像操作继续可用 |
| 回复设置 | 原全局设置；聊天 AI、模型连接、人设与回复配置；绘图、语音及各群功能可展开 |
| 系统设置 | Webhook、接口访问、离线通知等原系统配置，模型配置仍在“回复设置” |
| MCP 服务 | 服务添加、配置、启停及工具管理；详细配置可展开 |
| 技能管理 | 原 Skills 的安装、配置、启停、更新与卸载；详细说明可展开 |
| 文件存储 | 原 OSS 服务配置 |
| 运行日志 | 客户端、服务端日志与刷新 |
| 服务概况 | 原系统运行时间与资源信息 |

工作区上方保留微信账号选择、刷新、账号管理和详情入口；原账号运维确认步骤保持。内嵌微信客服跟随主系统日间/夜间主题，统一页签、表单和会话配色；切换主题保留正在编辑的内容和打开的设置窗口。手机端页签与设置入口自动换行。独立微信管理入口仍可使用个人主题设置，文档和 GitHub 链接仍在原用户菜单中。验证与维护见 [微信主题统一记录](changes/2026-11-12-wechat-theme-alignment.md)。

微信账号选择框的名称居中，页签整排居中并使用统一高度、间距，文字在按钮内居中；手机端按行换行。维护与验证见 [微信对齐记录](changes/2026-11-12-wechat-alignment.md)。

## 新版运营总览、评论与发布

- **运营总览**：顶部列出今天要处理的事（待人工回复、运行问题、排队中的发布），点卡片直达对应页面；AI 数字员工区显示五个平台账号的登录与启停状态。已登录且已获取真实昵称时显示“昵称 · 平台”，未登录或昵称未获取时只显示平台，不使用手工账号标签；名称随后台刷新更新。指标卡、发布分布和最近发布在下方，原平台运营数据保留，其余分析在“更多分析”中展开。
- **评论**：左侧按状态筛选，中间按帖子分组查看评论，点一条评论在右侧查看详情并处理；处理按钮与原来相同（人工回复、检测 App 人工回复、人工已处理、重新判断、删除）。
- **评论 / 私信账号选择**：已登录且检测到真实昵称时显示“昵称 · 平台”；未登录、状态未确认或未检测到昵称时只显示平台，不再使用手工账号标签。登录状态与昵称随后台刷新原位更新，保持当前选择。见 [互动账号名称](changes/2026-11-12-interaction-account-name.md)。
- **平台概览**：评论和私信顶部同时列出五个平台账号的待人工处理评论、私信、已采集数量及登录/采集状态。点“评论”或“私信”的数量即可切换对应账号与列表；评论默认进入待处理筛选，点账号标题则进入当前栏目。概览按全部可见的本地已采集记录统计，不代表平台尚未采到的消息数；未完成采集时明确标注。停用账号仍可查看历史，采集按钮禁用。详情按当前账号读取最近 200 条，超过时显示范围说明；后台更新保留选中账号和展开状态。维护见 [互动平台概览](changes/2026-11-12-interaction-overview.md)。
- **发布内容**：三步流程不变，右侧手机预览实时显示标题、正文和素材，可在所选平台间切换。

实现说明见 [新版布局记录](changes/2026-11-11-workspace-v2-layout.md)。

## 后台数据更新

转人工记录展示待处理消息的通知及企微送达状态，送达不代表人工已处理。点击“人工已处理”、确认平台回复成功或关闭消息后，对应转人工通知自动归档，从转人工列表、数量及企微通知列表移除，并停止后续通知重试；同一会话的其他待办继续保留。系统启动时会补查已处理消息的遗留通知。原消息、送达证据与幂等记录保留，不会撤回企微中的消息，也不会自动恢复机器人接管。首页和侧栏只统计未关闭、未删除、未处理的人工待办；本次已关闭 194 条历史待办，详见 [自动归档与首页清理](changes/2026-11-12-handoff-resolution.md)。

运营总览每 30 秒读取最新看板数据，平台账号每 5 秒同步状态。后台数据变化时原位更新对应文字、列表和状态，卡片、粒子球与管理面板沿用现有节点。响应生成时间单独更新。

展开区域和当前表单值保留。输入、确认弹窗及平台动作进行期间暂缓画面同步，后续轮询继续更新。侧栏刷新和筛选入口可主动重新读取当前数据。验证范围与维护方式见 [后台更新记录](changes/2026-11-12-dashboard-refresh-flicker.md)。

## 日间 / 夜间与光效

默认日间（晨雾浅色玻璃）；侧栏底部“夜间 / 日间”按钮切换到夜间（夜幕光边），选择保存在本机浏览器。旁边的光效按钮可关闭毛玻璃、背景流动和卡片倾斜，配置较低的电脑建议关闭；系统开启“减少动态效果”时默认关闭。主题只改变外观，不影响任何功能、接口或后台任务。内嵌微信客服已跟随主系统主题，内容创作工作台仍为原深色样式。实现与回退见 [日间 / 夜间主题记录](changes/2026-11-11-day-night-theme.md) 和 [微信主题统一记录](changes/2026-11-12-wechat-theme-alignment.md)。

## 运行开关与高级入口

- 全局运行开关、云端/采集服务及 AI 状态在左侧底部“运行状态”；刷新与退出也在侧栏底部。
- 单个平台运行、账号启停和智能回复仍在“平台账号”；评论/私信立即采集、频率与运行状态仍在对应页面。
- 浏览器状态与修复帮助在“系统设置 → 浏览器状态”，原浏览器执行与诊断在其“维护详情”；问题处理在“系统设置 → 问题记录”。
- 知识库提供文件增删改查、人设与 RAG 测试；微信自身的知识库页面仍属于微信机器人独立业务范围。

异常原因、来源、审核/发布结果、通知失败、转人工状态和必要确认继续显示。高级信息折叠只改变展开方式，不改变功能、接口或后台任务规则。
