# 视频号私信发送按钮修复（2026-09-10）

## 问题与根因

私信回复已生成并填入编辑框，但发送后没有新增己方消息，任务进入 `reply_unconfirmed`。当次证据同时记录了 `editorCleared: false`、`scopedEchoCount: 0` 和 `sendMethod: scoped-selector:.default.btn`。

视频号页面的 `.footer` 是纵向 flex 布局。`.default.btn` 对应整行宽度的 `div.weui-desktop-btn_wrp`，内部真正的 `button` 通过 `text-align: end` 靠右显示。点击容器中心落在空白处，不会触发子按钮上的发送事件。旧代码也无法通过外层容器正确判断内部按钮的禁用状态。

根因排查阶段通过现有 Local Agent 的只读页面检查和页面实际加载的静态资源核对 DOM、布局与事件绑定。

## 修复

将视频号私信发送选择器从 `.default.btn` / `.btn` 改为 `.default.btn button` / `.btn button`，限定在当前编辑框所属的 `.footer` 内。由原有可用性检查判断实际按钮，再点击一次。

发送成功仍要求编辑框清空、目标会话内新增完全匹配的己方回复。不增加回车补发或点击重试；既有不确定任务保持原状态，不能据此把历史失败改记为成功。
